# Founder Intelligence — канонический desktop-набор

Все изображения в этой папке являются горизонтальными desktop-макетами. Мобильные макеты намеренно отсутствуют.

## Основные страницы

| Файл | Назначение |
| --- | --- |
| `01-start-dashboard.png` | Стартовая страница, загрузка нового проекта и последний анализ. |
| `02-data-room.png` | Загрузка материалов, покрытие проекта и разрешение безопасного публичного поиска. |
| `03-analysis-progress-gate2.png` | Работа команды агентов и подтверждение первичного профиля стартапа. |
| `04-overview-readiness.png` | Понятный обзор: что работает, что мешает росту и что предлагает AI. |
| `05-metrics-finance.png` | Подтверждённые и рассчитанные метрики, проблема и способы усилить расчёт. |
| `06-market-competitors.png` | Рынок, конкуренты, позиционирование и происхождение внешних выводов. |
| `07-risks-questions.png` | Риски, противоречия и общий список важных уточнений. |
| `08-ai-action-plan.png` | Приоритетные улучшения и план 7/30/60/90 дней. |
| `09-report-center.png` | Gate 4, одобрение версии и единая линия JSON/HTML/PDF. |
| `10-admin-observability-v2.png` | LangGraph, LangSmith, privacy, gates, стоимость и целостность отчёта. |

## Центральный цикл AI-советника

| Файл | Назначение |
| --- | --- |
| `11-ai-advisor-next-question.png` | Один следующий лучший вопрос, причина приоритета и ожидаемый эффект. |
| `12-ai-advisor-answer.png` | Ручной ответ, файл, публичный поиск или пропуск; объяснение приватности. |
| `13-ai-advisor-updated-analysis.png` | Немедленный пересчёт покрытия, уверенности, метрик, рисков и рекомендации. |
| `14-ai-advisor-improved-plan.png` | Принятое AI-улучшение, сравнение версий и обновлённый план реализации. |

## Рекомендуемая последовательность для демонстрации

`01 → 02 → 03 → 04 → 11 → 12 → 13 → 14 → 05 → 06 → 07 → 08 → 09 → 10`

Экраны `07` и `08` остаются полноценными сводными страницами. Экраны `11–14` показывают интерактивные состояния, без которых прогрессивный AI-советник был бы неоднозначен для реализации.
